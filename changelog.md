# v1.2.8
- Loading scenes keep up with GD even when it lags, so every stage shows; the menu never goes back to the start of the scene.

# v1.2.7
- If GD finishes loading before the loading scene is done, the menu carries the scene on and finishes the change smoothly (sound too), so there is no sudden cut.
- Loading scenes glide with progress instead of jumping.

# v1.2.6
- Loading screens can play a day sound that crossfades into a night sound as GD loads, carrying on into the menu ("loading-sound-day" / "loading-sound-night").
- The menu background carries on from the loading screen without jumping.

# v1.2.5
- Packs can recolour things GD tints in code, like the level progress bars ("tint-swaps").

# v1.2.4
- Loading progress changes smoothly instead of in jumps.

# v1.2.3
- Loading screen animations can follow how far GD has loaded (for scenes that change as it loads).

# v1.2.2
- Clicking "Later" on the update popup now asks again next time GD opens, instead of skipping that version for good.

# v1.2.1
- The update check gives up quickly if GitHub doesn't answer, so it never holds anything up.

# v1.2.0
- Updates itself: when GD opens it checks for a newer version and asks if you want it. You can turn this off in the mod settings.

- Startup intros with sound, animated menu and loading screen backgrounds.
- Your own icons on the title screen.
- Recoloured lists, comments, profiles, text boxes, pause menu and end screen.
- Hides menu floors so the pack background shows through.
- Replaces Menu Shaders, LoadingScreenTweaks, Custom Startups and Happy Textures for my packs.
